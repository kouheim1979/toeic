# SoundBeat — 英語耳トレ

LINE登録やアカウント作成なしで使える、英語のリズム・弱形・聞き取りのオリジナル練習アプリです。

## 起動

[GitHub Pagesで開く](https://kouheim1979.github.io/toeic/soundbeat/)

iPhoneのSafariで開き、共有メニュー →「ホーム画面に追加」を選ぶとアプリとして使えます。
GitHub Pagesでの公開設定によっては、リンクが利用できるまで時間がかかる場合があります。

## 機能

- **リズム**：4パターンのビートと英文の聞き取り
- **弱い音**：30の弱形＋10の連結・短縮表現
- **耳テスト**：10問の3択クイズ、解説、端末内の学習記録

## 仕様と注意

HTML/CSS/JavaScriptのみ。広告・外部CDN・外部API・Cookieなし。
進捗のみブラウザの localStorage に保存されます。
音声は端末の SpeechSynthesis による合成音声であり、自然な英語の弱形・連結を完全に再現するわけではありません。
リズム音は Web Audio API で生成。端末・音声設定により読み上げが使えない場合があります。
公開ページの初回読み込み後は一部オフライン利用できます。

本アプリは「Beat Master」の公式版や複製ではなく、一般的な英語音声学を参考に作成した独立教材です。
