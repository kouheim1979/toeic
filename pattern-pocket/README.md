# Pattern Pocket — 80パターン英会話トレーニング

「聞く → 入れ替える → 自分の話をする → 会話する → 型を混ぜる」を、1問ずつ繰り返す英会話練習アプリです。

## アプリを開く

GitHub Pages で `main` ブランチのルートが配信されている場合は、次のURLで起動できます。

**https://kouheim1979.github.io/toeic/pattern-pocket/**

HTMLファイル単体でも動作する設計です。ブラウザーの音声読み上げ・音声認識は端末やブラウザーによって利用状況が異なります。

## 機能

- オリジナル80型と6場面の会話練習
- 1文2回読み上げ、Change/Addで文をつなげる練習
- 自由回答と会話の自己評価（AIによる自動添削ではありません）
- 学習記録・苦手復習・途中再開・自作教材の登録
- データのローカル保存とバックアップ

## 教材・プライバシー

収録する80パターンは**独自教材**であり、書籍『ネイティブなら12歳までに覚える 80パターンで英語が止まらない！』の公式教材・全文収録ではありません。出版社・著者とは無関係です。

学習記録は利用中のブラウザーの `localStorage` に保存され、別の端末とは自動同期されません。ブラウザーの音声認識機能が外部サービスを利用する場合があります。

## 公開ファイル

- `index.html`: アプリ本体。CSS・JavaScript・教材を内蔵した単独HTMLです。

本リポジトリの既存TOEICトレーナーとは独立したフォルダーです。
