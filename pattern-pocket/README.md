# Pattern Pocket — Small Wins (1.2.0)

小さな「言えた！」を、毎日に。80の独自パターンを「聞く → 入れ替える → 自分のこと → 会話 → 型をまぜる」で練習するアプリです。

## 開く

https://kouheim1979.github.io/toeic/pattern-pocket/

## 今回のデザイン変更

新聞・雑誌風の画面をやめ、青・白・オレンジの明るい学習画面に変更しました。

- 「今日のチャレンジ」と大きな開始ボタンを中心に配置。
- CSSで描く吹き出し型のキャラクター、丸いカード、押した手応えのあるボタン。
- 既存の学習記録に基づく目標リング、最近7日間のチェック。
- 内蔵パターンを1・5・10・25・50・80型練習すると達成バッジを表示。習得・正答・発音の認定ではありません。復習記録がある内蔵パターンを重複なく数え、独自教材はカウントしません。
- 問題の進行表示、完了時の星と一度だけの紙吹雪。動きを減らす設定に対応。

外部のサイトテンプレート、画像素材、追加の広告・追跡タグは使っていません。全サイトとの類似がないことを保証するものではありません。

## 構成

- `index.html`: 新しい画面の入口。
- `play.css`, `play.js`: Small Winsデザインと表示用処理。
- `pocket-mark.svg`: ロゴ。
- `engine-v1.html`: 元の単独HTML。学習エンジン・教材・保存形式はバイト単位で変更していません。
- `studio.css`, `studio.js`, `studio-mark.svg`: 前デザインのファイル。新しい入口からは読み込みません。

新しい入口はHTTPSまたはlocalhostで開いてください。`python -m http.server 8000` をこのフォルダーで起動して `http://localhost:8000/` を開くこともできます。新しいindex.html単体のfile://起動は対象外です。単独HTMLとして使う場合は `engine-v1.html` を使用します。

起動時に同一フォルダーのエンジンを取得しSHA-256を照合します。固定された自作コードだけを読み込み、外部URLや利用者の文章を実行するものではありません。不一致・取得失敗時は基本版へのリンクを表示します。

## 学習とプライバシー

保存キー `patternPocket.v1`、学習記録の構造、採点・自己評価・復習ロジック、80型、6場面を維持。新しいデザイン層は既存記録を読むだけで、得点や復習日を書き換えません。

自由回答は自己評価です。AI会話、自動文法添削、発音採点ではありません。保存は利用中のブラウザー内で、別端末に自動同期されません。音声認識はブラウザーの外部サービスを利用する場合があります。

内蔵教材は書籍の掲載順・全文・公式音声を再現したものではありません。出版社・著者の公式アプリではありません。

## 確認範囲

33項目の自動チェックに合格。画面幅320〜1440pxのホーム表示、9ステップ完了、誤答訂正、Change/Addの文の保持、自由回答の自己評価、実記録に応じたバッジ、再開用データの保持、検索、設定、6会話、エンジンのハッシュ不一致時の停止を確認しました。

検証環境ではブラウザーのネットワーク・ファイル遷移が管理ポリシーで制限されるため、ChromiumのDOMへHTMLを直接読み込み、fetchとlocalStorageをメモリー内のテスト用実装に置き換えました。SHA-256はPythonのhashlibで計算しています。公開URLの実ブラウザー表示、ブラウザー本来の永続保存、iPhone実機のマイク・音声再生はこのテストでは未検証です。

今回、広告コードと検索向け公開設定は変更していません。他のアプリのフォルダーも変更していません。
