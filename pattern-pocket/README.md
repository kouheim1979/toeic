# Pattern Pocket — The Speaking Room

80のオリジナルパターンを「聞く → 入れ替える → 自分のこと → 会話 → 型をまぜる」で練習する英会話アプリです。

## アプリ

https://kouheim1979.github.io/toeic/pattern-pocket/

2026-10-12に独自のSpeaking Roomデザインへ変更。墨色・アイボリー・朱色、活字風の見出し、音声トラックと番号付き索引を組み合わせたレイアウトです。外部サイトのテンプレートや画像素材は流用していません。全世界のサイトとの類似がないことを保証するものではありません。

## ファイルと起動

- `index.html`: 新しい公開画面の入口。
- `studio.css`: 画面全体とスマートフォン向けのデザイン。
- `studio.js`: 表示の変更と、検証済み学習エンジンの読み込み。
- `studio-mark.svg`: 独自のロゴマーク。
- `engine-v1.html`: 旧アプリをバイト単位で変更せず保存した学習エンジン。基本版として直接開くこともできます。

新しい画面はHTTPSまたはlocalhostで配信してください。ローカルではこのディレクトリで `python -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。新しい `index.html` 単体のfile://起動は対象外です。旧単独HTMLが必要な場合は `engine-v1.html` を使用します。

起動時に同じディレクトリの `engine-v1.html` を取得し、SHA-256を照合してから元のマークアップ・CSS・スクリプトを読み込みます。ユーザー入力や外部URLを実行する仕組みではありません。エンジンの不一致・取得失敗時は基本版へのリンクを表示します。学習ロジックと教材を変更せず、見た目だけを分離する構成です。

## 機能と記録

80型、6場面、2回読み上げ、Change/Add、復習、途中再開、教材登録、バックアップを維持しています。自由回答は例文比較と自己評価であり、AI自動添削ではありません。

学習記録の保存キー `patternPocket.v1`、公開URL、保存形式は変更していません。同じブラウザー・同じオリジンの既存記録を読み込みます。別端末へは自動同期されません。ブラウザーの音声認識が外部サービスを利用する場合があります。

## 教材

内蔵80項目と例文はアプリ独自の教材です。書籍『ネイティブなら12歳までに覚える 80パターンで英語が止まらない！』の掲載順・本文・公式音声を収録したものではなく、出版社・著者の公式アプリではありません。

今回の変更はデザインのみです。広告コード、広告審査設定、検索エンジン向け公開設定は変更していません。既存TOEICトレーナーを含む他のフォルダーも変更していません。
