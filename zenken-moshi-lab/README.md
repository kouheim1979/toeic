# 成績ラボ｜模試分析アプリ

英語学習アプリのリポジトリ [toeic](https://github.com/kouheim1979/toeic) 内にある、PINでロック解除する成績分析アプリです。

## アプリ

[成績ラボ（GitHub Pages）](https://kouheim1979.github.io/toeic/zenken-moshi-lab/)

## 単元分析（新トップ画面）

PIN認証後の初期画面は「単元の実力分析」です。既に利用中の端末でも、新版への初回移行時はここから開きます。

- **最優先の3分野**：直近の失点数、確認できる受験者平均との差、低得点の繰り返しを組み合わせた復習候補。機械的な最低得点率順とは異なります
- **改善傾向**：同じ学習分野・形式が複数回出題された場合だけ得点率の増減を表示。社会の広域な地理区分は比較から除外
- **単元詳細**：7月は正答設問数、8・9月は得点と配点、平均値が元票で確認できた項目のみ平均差、各回の内訳を展開表示
- **全回・個別回切替**：全部（累計）・7月・8月・9月、教科をすべて／個別に切り替え
- **根拠に応じた学習案**：確率、英作文、資料付き読解など、実際に失点した単元に即して具体的な復習の手順を示す

### 比較・集計で混同しないこと

1. 7月の設問○×は配点が不明のため、8・9月の得点・配点とは合算せず別枠で表示します。正解設問割合は得点率ではありません。
2. 8月・9月の単元累計は **（得点合計）÷（配点合計）** で求めます。配点や問題の難度は回によって異なります。
3. 数学の一次関数と方程式、理科の「音の発生」と「音の性質」のように内容が異なるものは統合しません。社会の地理は分類範囲が広いため改善・悪化を断定しません。
4. 受験者平均が欠けている単元は、平均を補完・推測せず「未入力」と表示します。
5. 優先順位と復習案は学習の目安です。合格可能性や学力向上を保証するものではありません。

## 主な機能

- 2026年7月・8月・9月の5教科の得点、偏差値、平均との差、順位推移
- 7月・8月・9月の各回を選んで**全5教科の単元詳細**を表示。7月は設問の○×（正誤数）、8・9月は単元別の得点／配点
- **教科別・全回累計**：同じ単元の得点・配点を集計、得点率・失点・出題回数を比較
- **5教科・全回累計**：全科目の単元を横断して弱点順位を表示
- 累計の単元を開くと各回の得点／配点が確認でき、得点率・失点・出題回数で並べ替え可能
- 各回の単元内訳をアプリから入力・編集でき、新しく登録した模試も累計に反映
- 苦手単元の優先順位（得点率、平均との差）
- 志望校判定の参照
- 目標点のシミュレーションと学習チェック
- 新しい模試結果の追加・修正、JSONバックアップ

## ロックと保存

PIN入力後にブラウザのWeb Crypto APIで暗号化された成績を復号します。
ログイン済み端末には、**有効期間30日のCookie** を保存して再入力を省略します。
「ロックする」を選ぶとその端末のCookieを削除します。

ソースには実名を含めていません。成績・学校判定・単元内訳は、PBKDF2（SHA-256、72万回）+ AES-GCMで暗号化した状態でのみコミットしています。ブラウザで編集した記録も暗号化して端末内に保存されます。

**重要：GitHub Pagesは静的な公開サイトです。** これはサーバー側のアクセス認証ではありません。短いPINは総当たりで推測できるため、本格的な機密データの保護用途には適しません。家族での簡易的な閲覧制限を想定しています。CookieはJavaScriptから読み取り可能で、HttpOnlyなサーバー認証Cookieではありません。

## 注意

- GitHub上のソースファイルは誰でもダウンロードできます（成績部分は暗号文）。
- 共有端末では「ロックする」を押してから離れてください。
- JSONとして書き出すバックアップは**暗号化されません**。安全に管理してください。
- 7月の単元別○×の記録を、以前共有された第2回模試の5教科の設問別結果から復元しています（設問数に対する正答数。国語の記述部分点は別表示）。
- 7月の各設問の**配点は不明**なので、正誤数を点数へ換算していません。単元別**得点累計**は現在**8月・9月の2回分**のみです。7月の○×は個別画面と全回累計内の「7月｜設問別の正誤（別集計）」に表示し、点数合計に混ぜません。
- 得点率は**各回の得点を合計 ÷ 各回の配点を合計**した値です。単純な得点率の平均ではありません。単元名が少し違う場合は同等と判断できるもののみ統合し、出題範囲が異なるものは分けています。
- 偏差値・順位・志望校判定は成績表の値を参照します。目標点から合格可能性を自動推定するものではありません。
