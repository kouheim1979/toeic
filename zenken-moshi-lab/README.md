# 成績ラボ｜模試分析アプリ

英語学習プロジェクト `toeic` 内に置いた、独立して動く模試分析アプリです。

## アプリを開く

[成績ラボを開く（GitHub Pages）](https://kouheim1979.github.io/toeic/zenken-moshi-lab/)

`zenken-moshi-lab/index.html` だけで動作します。追加インストールやAPIキーは不要です。

## できること

- 5教科の得点・偏差値・平均との差・順位の比較
- 教科ごとの推移と単元別の得点分析
- 志望校の判定値の表示（個人用JSONを読み込んだ場合）
- 次回目標点のシミュレーション
- 4週間の学習チェック
- 新しい模試結果の入力、編集、削除
- JSONバックアップの保存と復元

## 個人データの取り扱い

**このGitHubリポジトリは公開されています。個人の成績や学校判定はコミットしないでください。**

公開版の `index.html` は架空のデモ成績のみを含みます。実際の成績を使う場合は、アプリを開いて **「記録」→「バックアップを読み込む」** から個人用 `.json` ファイルを読み込んでください。読み込んだデータは閲覧中の端末のブラウザ保存領域（localStorage）に保存され、GitHubへ自動送信されません。

別の端末で使う場合はアプリ内の「データを書き出す」を使い、JSONファイルを安全に移してください。共有端末では保存データの扱いに注意してください。

## 注意

偏差値や合格判定は得点だけから推定していません。成績表に記載の値を入力してください。判定は参考情報であり、合否を保証するものではありません。
