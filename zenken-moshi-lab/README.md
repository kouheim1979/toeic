# 成績ラボ｜模試分析アプリ

英語学習アプリのリポジトリ [toeic](https://github.com/kouheim1979/toeic) 内にある、PINでロック解除する成績分析アプリです。

## アプリ

[成績ラボ（GitHub Pages）](https://kouheim1979.github.io/toeic/zenken-moshi-lab/)

## 主な機能

- 2026年7月・8月・9月の5教科の得点、偏差値、平均との差、順位推移
- 8月・9月の**全5教科・各単元の得点内訳**を月別に切り替えて表示
- 苦手単元の優先順位（得点率、平均との差）
- 志望校判定の参照
- 目標点のシミュレーションと学習チェック
- 新しい模試結果の追加・修正、JSONバックアップ

## ロックと保存

PIN入力後にブラウザのWeb Crypto APIで暗号化された成績を復号します。
ログイン済み端末には、**有効期間30日のCookie** を保存して再入力を省略します。
「ロックする」を選ぶとその端末のCookieを削除します。

ソースには実名を含めていません。成績・学校判定・単元内訳は、PBKDF2（SHA-256、72万回）+ AES-GCMで暗号化した状態でのみコミットしています。ブラウザで編集した記録も暗号化して端末内に保存されます。

**重要：GitHub Pagesは静的な公開サイトです。** これはサーバー側のアクセス認証ではありません。短いPINは総当たりで推測できるため、本格的な機密データの保護用途には適しません。家族での簡易的な閲覧制限を想定しています。CookieはJavaScriptから読み取り可能で、HttpOnlyなサーバー認証Cookieではありません。

## 注意

- GitHub上のソースファイルは誰でもダウンロードできます（成績部分は暗号文）。
- 共有端末では「ロックする」を押してから離れてください。
- JSONとして書き出すバックアップは**暗号化されません**。安全に管理してください。
- 7月の**教科別得点**は登録済みですが、単元内訳は未登録です。8月・9月の単元別配点と得点は成績表に基づいています。
- 偏差値・順位・志望校判定は成績表の値を参照します。目標点から合格可能性を自動推定するものではありません。
