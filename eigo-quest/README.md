# えいごヒマつぶしクエスト — SENTENCE LAB

REMSを参考にした、独自教材による反復・置換・文の拡張トレーニングです。QQEnglishの公式・公認アプリではなく、公式教材・公式音声は収録していません。公式レッスンとのレベル対応や同等の学習効果は保証しません。

## 起動

`eigo-quest/index.html` がアプリ本体です。HTML・CSS・JavaScript・教材を1ファイルに含みます。リポジトリ直下の既存TOEICアプリは変更しません。

GitHub Pagesの公開先： https://kouheim1979.github.io/toeic/eigo-quest/

## 練習

- 12レッスン・120の独自ドリル。復唱、置換、拡張、否定文、疑問文、応答、時制変換。
- 「おまかせ10問」は苦手・復習期限を考慮し、最大4問の復習と通常問題を組み合わせます。
- 発話モードは、聞く → 全文で答える → 見本を確認 → 自己評価。自動発音採点ではありません。
- 語順タップは自動判定。誤答だけで見本は開きません。見本を見た後の正解や再試行は、初回の自力正解と区別します。
- 既存100語・5種類の4択クイズ、XP、バッジ、苦手復習、お気に入り、日別・ジャンル別記録、設定を維持しています。

## 音声・プライバシー

ブラウザのSpeechSynthesisのうち、端末内の英語音声（localServiceがtrueのもの）だけを利用します。音声がない場合も文字・語順練習ができます。声・読み上げ可否は端末に依存します。

録音はユーザーが録音ボタンを押した場合のみマイクを要求し、最大20秒です。録音は一時的なメモリ内のみに保持し、問題・画面を移ると破棄します。サーバーへの音声送信や外部音声認識は行いません。HTTPSおよび対応ブラウザが必要です。

## 保存・移行

既存キー `eigo_himatsubushi_quest_max_v2` を維持し、データのversionは3です。既存の学習データを検証して読み込み、新しい反復学習の記録はremsフィールドに追加します。保存できない環境では警告し、メモリ上で動作を続けます。

ブラウザ・端末・公開元が変わるとlocalStorageは自動では移りません。設定の「記録を書き出す」「記録を読み込む」でJSONバックアップを移してください。読み込み時は形式・サイズを検証し、置き換え前に確認します。

## 教材を追加する場所

- 単語：`QUESTIONS` 配列。
- 反復：`lesson(id, title, level, rows)` 呼び出し。rowsは `[種類, 元の英文, 英語指示, 日本語指示, 見本文, 日本語訳, ポイント]`。
- 公開済みの問題ID・レッスンIDは履歴の参照に使うため変更しないでください。
- 難易度1〜3はこのアプリ独自の分類で、公式REMSのレベルとは対応しません。

## 検証範囲

開発環境のChromiumへ完成HTMLを直接読み込ませ、255項目を確認しました。全120ドリルの語順判定、既存5モード、320〜1280pxの画面幅、二重回答防止、旧データ読込、壊れたJSON・保存不可、タイマー・音声キャンセル等を含みます。

検証環境では通常のページナビゲーションに制限があったため、DOM読み込みによる検証です。保存の継続・移行はStorageテストダブルも使用しています。iPhone実機、実音声の音質、実マイク、Safari固有の挙動は未確認です。
